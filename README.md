# AccFlow — โปรแกรมบัญชีออนไลน์สำหรับ SME ไทย

เว็บแอปบัญชีแบบ Static (HTML/CSS/JavaScript ล้วน ไม่ต้องมีเซิร์ฟเวอร์) — Deploy บน **GitHub Pages** และเก็บ/สำรองข้อมูลบน **Google Drive + Google Sheets** ผ่าน Google Apps Script

## ฟังก์ชันหลัก

|---|---|

## หลักการบัญชีที่ผูกสูตรไว้

ทุกเอกสารที่ **อนุมัติ** จะถูกลงบัญชีคู่ (Double-entry) อัตโนมัติ — งบทดลองสมดุลเสมอ

| เหตุการณ์ | เดบิต | เครดิต |
|---|---|---|
| ใบวางบิล (ขายเชื่อ) | ลูกหนี้การค้า | รายได้ขาย/บริการ, ภาษีขาย (หรือภาษีขายยังไม่ถึงกำหนด กรณีบริการ) |
| ↳ สินค้านับสต็อก | ต้นทุนขาย | สินค้าคงเหลือ (ทุนถัวเฉลี่ย) |
| ใบเสร็จรับเงิน | เงินสด/ธนาคาร, ภาษีถูกหัก ณ ที่จ่าย | ลูกหนี้การค้า (+ โอนภาษีขายยังไม่ถึงกำหนด → ภาษีขาย) |
| ใบรับสินค้า / ค่าใช้จ่าย | สินค้าคงเหลือ/ค่าใช้จ่าย, ภาษีซื้อ | เจ้าหนี้การค้า |
| จ่ายชำระ | เจ้าหนี้การค้า | เงินสด/ธนาคาร, ภาษีหัก ณ ที่จ่ายค้างจ่าย |
| เงินเดือน | เงินเดือน, ประกันสังคมนายจ้าง | ธนาคาร, ประกันสังคมค้างจ่าย, ภ.ง.ด.1 ค้างจ่าย |
| ค่าเสื่อมราคา (สิ้นเดือน) | ค่าเสื่อมราคา | ค่าเสื่อมราคาสะสม |

**สูตรเอกสาร:** รวมเงิน − ส่วนลด = มูลค่าก่อนภาษี → VAT 7% (แยก/รวมใน/ไม่มี) → ยอดรวม − หัก ณ ที่จ่าย (คิดจากมูลค่าก่อน VAT) = ยอดชำระสุทธิ

**จุดรับรู้ภาษีขาย (ม.78):** บริการ = เมื่อรับชำระเงิน, ขายสินค้า = เมื่อส่งมอบ/ออกใบแจ้งหนี้ (ตั้งค่าได้)

**ปีบัญชี:** บัญชีรายได้/ค่าใช้จ่ายของปีก่อนจะถูกโอนเข้ากำไรสะสมอัตโนมัติในงบทดลองและงบแสดงฐานะการเงิน

## Deploy ขึ้น GitHub Pages

1. สร้าง repository ใหม่บน GitHub แล้ว push โค้ดนี้ขึ้น branch `main`
   ```bash
   git remote add origin https://github.com/<user>/<repo>.git
   git push -u origin main
   ```
2. ไปที่ **Settings → Pages → Build and deployment → Source: GitHub Actions**
3. Workflow `.github/workflows/deploy.yml` จะ deploy ให้อัตโนมัติทุกครั้งที่ push — เว็บจะอยู่ที่ `https://<user>.github.io/<repo>/`

## เชื่อมต่อ Google Drive / Sheets (เก็บข้อมูลและสำรองข้อมูล)

1. เปิด [script.google.com](https://script.google.com) → New project → วางโค้ดจาก `google-apps-script/Code.gs`
2. เลือกฟังก์ชัน `setup` → Run → อนุญาตสิทธิ์ → คัดลอก **API Token** จาก Execution log
3. **Deploy → New deployment → Web app** · Execute as: *Me* · Who has access: *Anyone* → คัดลอก URL
4. ในเว็บ AccFlow ไปที่ **ตั้งค่า → Google Drive / Sheets** ใส่ URL + Token → ทดสอบการเชื่อมต่อ

ระบบจะ:
- บันทึกข้อมูลทั้งหมดเป็นไฟล์ `AccFlow Data/accflow-data.json` บน Google Drive ของคุณ (ซิงก์อัตโนมัติทุกครั้งที่บันทึก)
- เขียนตาราง รายชื่อ / สินค้า / เอกสาร / สมุดรายวัน / งบทดลอง ลง Google Sheets “AccFlow Database” (เมื่อกด “ซิงก์ขึ้น + อัปเดต Google Sheets”)
- สำรองข้อมูลอัตโนมัติทุกวันเวลา 02:00 น. เก็บย้อนหลัง 60 ชุด และกู้คืนได้จากหน้าตั้งค่า

> **ความปลอดภัย:** Token ใช้ยืนยันทุกคำขอ และไม่ถูกบันทึกลงไฟล์ข้อมูลบน Drive · เว็บ GitHub Pages เป็นสาธารณะ แต่ข้อมูลอยู่ในเบราว์เซอร์ของผู้ใช้และใน Google Drive ของเจ้าของเท่านั้น · หากต้องการเปลี่ยน Token ให้รันฟังก์ชัน `rotateToken`

## ทดลองใช้งานในเครื่อง

```bash
python3 -m http.server 8000
```
แล้วเปิด http://localhost:8000 → กด “โหลดข้อมูลตัวอย่าง”
